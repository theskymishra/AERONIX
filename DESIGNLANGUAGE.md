AERONIX Design Language v1.0
1. Typography
We'll use Inter as the primary UI typeface.
Usage	Weight	Purpose
Display	600–700	Major dashboard headings
H1	600	Page titles
H2	600	Section headings
H3	500–600	Card/section titles
Body	400	Normal content
Medium	500	Labels and navigation
Semibold	600	Important values/actions
Mono	400–500	IDs, technical values, timestamps
The typography should feel clean and compact, rather than oversized.
2. Spacing
We'll use a consistent 4px base spacing system:
4   px
8   px
12  px
16  px
20  px
24  px
32  px
40  px
48  px
64  px

Small values → controls and internal spacing.
Larger values → page sections and dashboard composition.
3. Surfaces
AERONIX will primarily use a deep, sophisticated dark interface.
Hierarchy:
Application background
        ↓
Elevated surface
        ↓
Card / panel
        ↓
Interactive surface
        ↓
Focused / selected surface
We want visible depth without making everything look like transparent glass.
Glass treatment is reserved for selected premium UI elements, especially future 3D experiences and command-center interactions.
4. Borders
Borders should be:
subtle
low-contrast
consistent
used to establish structure rather than decoration
Typical:
1px solid
low-opacity neutral
Focused elements can use a stronger accent border/glow.
5. Shadows & Elevation
We'll use a small elevation hierarchy:
Level 0 → flat
Level 1 → cards
Level 2 → dropdowns / popovers
Level 3 → dialogs / command center
Level 4 → premium floating elements
Shadows should be soft and deep, not exaggerated.
6. Gradients
Gradients are part of AERONIX's identity, but we'll use them selectively.
They'll primarily appear in:
dashboard hero areas
selected data visualizations
active states
3D environments
Organization DNA
Skills Galaxy
premium emphasis areas
They should create depth and intelligence, not turn the whole interface into a gradient.
7. Motion
Motion should communicate state and hierarchy, not simply look impressive.
We'll use:
fast micro-interactions
smooth hover transitions
subtle scale changes
panel entrance/exit
layout transitions
controlled 3D camera movement
General philosophy:
Fast for controls. Smooth for surfaces. Cinematic for 3D.
And importantly, we will respect reduced-motion preferences.
8. Light / Dark Strategy
AERONIX will support both:
Dark mode
primary premium experience
deeper surfaces
subtle glow/depth
ideal for the 3D experiences
Light mode
clean
high contrast
professional
suitable for long HR/admin workflows
